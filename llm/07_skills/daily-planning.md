# Skill — Daily Planning

A workflow for starting a productive day.

---

## When to use

At the start of a work session when you have multiple things to do and need to prioritise.

## Steps

1. Read `02_state/next_actions.md` for pending tasks
2. Read `02_state/current_state.md` for context on what's active
3. Ask the user: "What's your energy level and available time today?"
4. Present the task list sorted by priority
5. Suggest a focused scope for the session (2–3 items max)
6. Confirm the plan, then start on item 1
