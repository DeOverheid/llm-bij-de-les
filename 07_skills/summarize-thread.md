# Skill — Summarize Thread

Condense a long conversation or thread into a structured summary.

---

## When to use

When a conversation has gotten long and the key points need to be extracted and saved.

## Steps

1. Read the full thread or content provided
2. Extract: decisions made, actions taken, open questions
3. Write a summary with these sections:
   - **What was discussed** — 2–3 sentence overview
   - **Decisions** — bullet list of what was decided
   - **Actions taken** — what actually changed
   - **Open items** — what still needs to happen
4. Present the summary for review
5. If approved, save to the appropriate file
